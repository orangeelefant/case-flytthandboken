# Case study — Flytthandboken

How [Flytthandboken](https://flytthandboken.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Flytthandboken

Flytthandboken är en fri kunskapsbank om att flytta i Sverige. Tidslinjen går från uppsägning till avflyttningsbesiktning, med guider om hyresrätt, bostadsköp, adressändring, flyttstäd och utlandsflytt, mallar i Word och PDF, beslutsträd och räknare. Varje guide hänvisar till lagtext och myndigheternas källor. Stadssidor för Sveriges större orter. På svenska och engelska.

→ [flytthandboken.se](https://flytthandboken.se)
